= Get Pump

Get a list of all Pumps and Valves.

== URL

`GET http://localhost:8080/getPump`

include::../_responseBody.adoc[]

| ID | String | Unique ID of the Pump or Valve.
| Name | String | Name of the Pump or Valve.
| ClassName | String | Class Name of the Pump or Valve.

// color slot/swatch
{set:key-name:ColorSlot}
include::../Models/_colorSlot.adoc[]

// bounding box
{set:key-name:BoundingBox}
include::../Models/_boundingBox.adoc[]

// power info fields
include::../Models/_powerInfo.adoc[]

| DesignHeadLift | Float | How high this pump pushes fluid above itself at full flow, in metres (Mk.1 20, Mk.2 50; 0 for a valve).
| MaxHeadLift | Float | Height at which its flow stops, in metres (Mk.1 22, Mk.2 55; 0 for a valve).
| HeadLift | Float | Head lift it's working against right now, in metres: the height of the fluid pushing back on it, as on its in-game panel. It also sits at the max when the line is full and backed up.
| HeadLiftPercent | Float | HeadLift as a percentage of MaxHeadLift.
| Flow | Float | Flow through the pump or valve, in m³ per minute.
| FlowPercent | Float | Flow as a percentage of MaxFlow.
| FlowLimit | Float | The flow limit set on it, in m³ per minute; -1 = fully open.
| MaxFlow | Float | Most it can pass, in m³ per minute (set by the pipes on it).
| Fluid | String | Name of the fluid going through it ("" if none).
| FluidClassName | String | Class Name of that fluid.

{set:key-name:location0}
{set:key-description:Location of its first pipe connection}
include::../Models/_location.adoc[tags=!rotation]
| ConnectionType0 | String | What the first connection is: `Consumer` = the pump's input, `Producer` = its output.
| ConnectedTo0 | String | ID of the pipe on the first connection ("" if none).

{set:key-name:location1}
{set:key-description:Location of its second pipe connection}
include::../Models/_location.adoc[tags=!rotation]
| ConnectionType1 | String | What the second connection is (`Consumer` / `Producer`).
| ConnectedTo1 | String | ID of the pipe on the second connection ("" if none).
