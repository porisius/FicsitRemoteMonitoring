= Get Vehicles

Gets a list of all wheeled vehicles (explorers, tractors, trucks, fluid trucks, factory carts, cyber wagons, etc.).

`getExplorer` only retrieves Explorers +
`getTractor` only retrieves Tractors +
`getTruck` only retrieves Trucks +
`getFactoryCart` only retrieves Factory Carts

Vehicles that the game's vehicle subsystem does not track (such as the Cyber Wagon, which has no autopilot) are included with an empty `Route` and `LocationSource` `Actor`.

== URL

`GET http://localhost:8080/getVehicles`

include::../_responseBody.adoc[]

| ID | String | Unique ID of the vehicle.
| Name | String | Name of the vehicle.
| ClassName | String | ClassName of the vehicle type.

{set:key-name:location}
{set:key-description:Location details of the Vehicle. For vehicles driving on autopilot this is the autopilot's simulated position, which keeps updating when no player is nearby.}
include::../Models/_location.adoc[]

| LocationSource | String | Where `location`, `features` and `ForwardSpeed` come from +
- `Autopilot`: the vehicle's autopilot (vehicle is driving its route) +
- `Actor`: the vehicle actor itself (driven by a player, parked, or no autopilot)
| PathName | String | The vehicle's route as stop names (station names, or `Waypoint` for non-station points) joined by ` -> ` (empty if the vehicle has no route)

| Route | Object[] | The stops of the vehicle's route, in order
| {depth}  Index | Integer | Position of the stop in the route
| {depth}  Name | String | Station name of the stop (`Waypoint` if the route point is not a station)
| {depth}  IsStation | Boolean | Is the stop a docking station?
| {depth}  IsNextStop | Boolean | Is this the stop the vehicle is currently heading to?
| {depth}  PathNodeGUID | String | GUID of the vehicle path node for the stop

| NextStop | String | Name of the stop the vehicle is currently heading to (empty if none)
| NextStopIndex | Integer | Index in `Route` of the next stop (-1 if none)
| IsCurrentlyDocking | Boolean | Is the vehicle currently docking at a station?
| AutoPilotStatus | String | Autopilot error status +
- `None`: No error +
- `Station Unreachable`: Station Unreachable +
- `Not On-Path`: Not On-Path +
- `Too Few Stations`: Too Few Stations +
- `No Fuel`: No Fuel +
- `Deadlocked`: Deadlocked
| Driver | String | Player Name of Vehicle Driver
| CurrentGear | Integer | Transmission Gear
| ForwardSpeed | Float | Current Speed in km/h
| EngineRPM | Float | RPM of Engine
| ThrottlePercent | Float | Throttle input
| Airborne | Boolean | Is the vehicle making a jump
| FollowingPath | Boolean | Is the vehicle following a path
| Autopilot | Boolean | Auto pilot engaged?
| HasFuel | Boolean | Does the vehicle have fuel
| FuelConsumption | Float | Fuel Consumption in MegaWatts

| Inventory | Object[] | A list of items.
include::../Models/_inventoryItem.adoc[]

| FuelInventory | Object[] | A list of Fuel.
include::../Models/_inventoryItem.adoc[]
include::../Models/_features.adoc[]

|===
