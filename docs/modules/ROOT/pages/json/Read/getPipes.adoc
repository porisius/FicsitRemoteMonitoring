= Get Pipes

Get a list of all Pipes.

== URL

`GET http://localhost:8080/getPipes`

include::../_responseBody.adoc[]

| ID | String | Unique ID of the Pipe.
| Name | String | Name of the Pipe Type.
| ClassName | String | Class Name of the Pipe.

// color slot/swatch
{set:key-name:ColorSlot}
include::../Models/_colorSlot.adoc[]

// bounding box
{set:key-name:BoundingBox}
include::../Models/_boundingBox.adoc[]

// Spline Data
{set:key-name:SplineData}
include::../Models/_splinedata.adoc[]

{set:key-name:location0}
{set:key-description:Start Location of the Pipe}
include::../Models/_location.adoc[tags=!rotation]
| Connected0 | Boolean | Is Pipe Connected at starting point?

{set:key-name:location1}
{set:key-description:End Location of the Pipe}
include::../Models/_location.adoc[tags=!rotation]
| Connected1 | Boolean | Is Pipe Connected at ending point?
| ConnectedTo0 | String | ID of the building the pipe is connected to at its starting point ("" if none): another pipe, a junction, pump, valve, machine, fluid buffer… Follow these to trace a line from piece to piece.
| ConnectedTo1 | String | ID of the building the pipe is connected to at its ending point ("" if none).
| ConnectedType0 | String | What the connection at the starting point is plugged into: `Producer` (fluid comes out of it: an extractor's or machine's output), `Consumer` (fluid goes into it: a machine's or generator's input), `Any` (another pipe, a junction, buffer…) or "" if nothing.
| ConnectedType1 | String | The same for the ending point.

| Length | Float | Length of the Pipe in centimetre (cm).
| ItemsPerMinute | Float | Speed of the Pipe.
| Fluid | String | Name of the fluid in the pipe's network ("" if none yet).
| FluidClassName | String | Class Name of that fluid.
| Content | Float | Fluid in this pipe right now, in cubic metres (m³).
| Capacity | Float | How much this pipe holds, in m³.
| Flow | Float | Flow through this pipe, in m³ per minute (a snapshot of the simulation; can swing).
| MaxFlow | Float | Most this pipe can carry, in m³ per minute (300 Mk.1, 600 Mk.2).
| PipeNetworkID | Integer | ID of the game's pipe network this pipe belongs to.
